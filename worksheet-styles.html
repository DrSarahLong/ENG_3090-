Set Up Your Styles

By the end of this worksheet your IMRAD report will virtually format itself. You will teach your word processor five styles, and it will apply them the same way on every page, so that when you're ready to format your IMRAD report, you can create a similar style sheet and not have to futz with it again.

Download the Word version Print this worksheet Build the Report → Thursday's module →

What a style is, and why it saves you

A style is a saved set of formatting with a name, such as Heading 1. When you apply a style instead of bolding and resizing by hand, three things happen:

  • Every heading at the same level looks identical, which abides the rule of repetition.
  • You can change every heading in the report with one edit.
  • Your headings become structural, which is what builds a table of contents (though we will not be using one for our IMRAD reports) and what screen readers use to move through a document. It's good to know how to do this for future technical reports even if we don't use it for the IMRAD report style.

You need: some portion of your report open in Google Docs or Word.

How to use this worksheet: read the style sheet, then follow Track A (Google Docs) or Track B (Word).

The house style sheet

This is your brief. Treat it the way a writer treats a publisher's style sheet: follow it exactly.

Use one serif font for everything. Georgia or Times New Roman both work, but are not your only two options.

Page setup: 1-inch margins on all sides, with the page number at the top right.

Track A: Google Docs

The pattern is the same for every style: format one example by hand, then tell Docs to update the style to match it.

A1. Set up Normal text

  1. Triple-click an ordinary body paragraph to select it. Do not pick a heading.
  2. In the toolbar, set the font to Georgia and the size to 12. Make sure bold is off.
  3. Go to Format > Line & paragraph spacing and choose Single.
  4. Go to Format > Line & paragraph spacing > Custom spacing. Set Before to 0 and After to 8. Click Apply.
  5. Go to Format > Align & indent > Left.
  6. With the paragraph still selected, go to Format > Paragraph styles > Normal text > Update ‘Normal text’ to match.

Every body paragraph in your document should change at once.

A2. Set up Heading 1

  1. Click in the line that says Introduction. If you have not typed it yet, type it on its own line.
  2. Go to Format > Paragraph styles > Heading 1 > Apply ‘Heading 1’.
  3. Select the whole line. Set the font to Georgia, the size to 16, and turn bold on.
  4. Go to Format > Line & paragraph spacing > Custom spacing. Set Before to 18 and After to 6. Click Apply.
  5. With the line still selected, go to Format > Paragraph styles > Heading 1 > Update ‘Heading 1’ to match.

A3. Set up Heading 2 and Title

Repeat the A2 steps twice, using the numbers from the style sheet:

  • Heading 2: pick one subsection heading. Apply Heading 2, format it (12 pt bold, 12 before, 3 after), then choose Update ‘Heading 2’ to match.
  • Title: pick your report title. Apply Title, format it (26 pt bold, 0 before, 12 after), then choose Update ‘Title’ to match.

A4. Apply the styles to your whole draft

  1. Click in each section heading (Methods, Results, Discussion, References, Appendix) and apply Heading 1 from the styles menu in the toolbar.
  2. Click in each subsection heading and apply Heading 2.
  3. Do not bold or resize anything by hand. If a heading looks wrong, apply its style again.

A5. Format your captions

Google Docs has no built-in caption style, so you format one caption and copy it.

  1. Under your first figure, type the caption in this pattern: Figure 1. What the figure shows, N = your sample size.
  2. Select the caption. Set it to 10 pt. Use Custom spacing to set Before to 0 and After to 12.
  3. Select only the label (Figure 1.) and make it bold.
  4. To copy the look to the next caption: select the finished caption, click Paint format in the toolbar, then click the next caption. Check that the label is still bold and fix it if not.

A6. Set up the page

  1. Go to File > Page setup. Make sure the document is set to Pages, not Pageless, and set all four margins to 1 inch.
  2. Go to Insert > Page numbers and choose the option that puts the number at the top right.

Track B: Microsoft Word

These steps are written for the Word desktop app on Windows. On a Mac, hold Control and click wherever a step says right-click. Word in a web browser has fewer style tools, so use the desktop app if you can.

The pattern is the same for every style: format one example by hand, then tell Word to update the style to match it.

B1. Set up Normal

  1. Triple-click an ordinary body paragraph to select it. Do not pick a heading.
  2. On the Home tab, set the font to Georgia and the size to 12. Make sure bold is off.
  3. On the Home tab, click Line and Paragraph Spacing, then Line Spacing Options.
  4. In the dialog, set Before to 0 pt, After to 8 pt, Line spacing to Single, Alignment to Left, and Special to (none). Click OK.
  5. With the paragraph still selected, find the Styles gallery on the Home tab. Right-click Normal and choose Update Normal to Match Selection.

Every body paragraph in your document should change at once.

B2. Set up Heading 1

  1. Click in the line that says Introduction. If you have not typed it yet, type it on its own line.
  2. In the Styles gallery, click Heading 1.
  3. Select the whole line. Set the font to Georgia, the size to 16, the font color to black, and turn bold on. Word's default headings are blue, so do not skip the color.
  4. Open Line Spacing Options again. Set Before to 18 pt and After to 6 pt. Click OK.
  5. With the line still selected, right-click Heading 1 in the Styles gallery and choose Update Heading 1 to Match Selection.

B3. Set up Heading 2 and Title

Repeat the B2 steps twice, using the numbers from the style sheet:

  • Heading 2: pick one subsection heading. Click Heading 2 in the gallery, format it (12 pt bold, black, 12 before, 3 after), then right-click Heading 2 and choose Update Heading 2 to Match Selection.
  • Title: pick your report title. Click Title in the gallery, format it (26 pt bold, black, 0 before, 12 after), then right-click Title and choose Update Title to Match Selection.

B4. Apply the styles to your whole draft

  1. Click in each section heading (Methods, Results, Discussion, References, Appendix) and click Heading 1 in the Styles gallery.
  2. Click in each subsection heading and click Heading 2.
  3. Do not bold or resize anything by hand. If a heading looks wrong, click its style again.

B5. Add and format your captions

Word numbers captions for you and gives them their own style.

  1. Click your first figure to select it.
  2. On the References tab, click Insert Caption.
  3. In the Label list, choose Figure. Click OK.
  4. After the label Word inserts, type a period and your caption: what the figure shows, N = your sample size.
  5. A style named Caption now appears in the Styles gallery. Right-click it and choose Modify.
  6. Set the font to Georgia, the size to 10, the color to black, and turn italic off. Click OK.
  7. Select only the label (Figure 1.) and make it bold. Repeat steps 1 to 4 and this step for each figure.

B6. Set up the page

  1. Go to Layout > Margins > Normal to set 1-inch margins on all sides.
  2. Go to Insert > Page Number > Top of Page and choose the plain number on the right.

Check your work

The outline check

Your headings should now work as a map of the report.

  • Google Docs: go to View > Show outline. The outline opens on the left side of the document.
  • Word: go to the View tab and choose Navigation Pane, then switch to the Headings tab in the pane.

Read the list from top to bottom. It should say Introduction, Methods, Results, Discussion, References, Appendix, in that order. A heading that is missing from the list was formatted by hand. Go back and apply its style.

The change test

This proves the styles are doing the work.

  1. Select one Heading 1 and change its size to 20.
  2. Update the Heading 1 style to match, the same way you did in step A2 or B2.
  3. Scroll through the report. Every Heading 1 should now be 20 pt.
  4. Change it back to 16 and update the style again.

Done checklist

  • Body text is 12 pt serif, single-spaced, with space after each paragraph
  • Every section heading uses Heading 1 and every subsection heading uses Heading 2
  • The outline lists Introduction, Methods, Results, Discussion in order
  • Every figure has a caption directly under it that starts with a bold label
  • Margins are 1 inch and page numbers are at the top right
  • The change test worked

If something goes wrong

ProblemFix
A heading does not show up in the outline or Navigation PaneIt was formatted by hand. Click in it and apply Heading 1 or Heading 2.
You updated a style but some paragraphs did not changeThose paragraphs have hand formatting on top of the style. Select them and apply the style again.
Text pasted from Project 1, 2, or 3 looks different from the restPaste without formatting (Ctrl+Shift+V, or Cmd+Shift+V on a Mac), then apply your styles.
Word headings are still blueSelect one, set the font color to black, and update the style to match.
Body text changed when you updated a headingYou had body text selected. Undo, select only the heading line, and update again.
Google Docs will not show page numbers or marginsThe document is set to Pageless. Go to File > Page setup and switch to Pages.
